روزآرا - نسخه دارای دیتابیس و بکاپ

دیتابیس: IndexedDB داخلی مرورگر، با ذخیره محفظه رمزگذاری شده AES-GCM.
رمز ورود: برای رمزگشایی اطلاعات و بازیابی فایل بکاپ ضروری است.
بکاپ: از تنظیمات برنامه، خروجی JSON رمزگذاری شده تهیه کنید.
بازیابی: از تنظیمات برنامه فایل بکاپ را انتخاب کنید؛ سپس با رمز عبور همان بکاپ وارد شوید.
نسخه‌های قدیمی JSON بدون رمز نیز قابل وارد کردن هستند؛ با احتیاط استفاده کنید.
اثر انگشت پس از انتقال بکاپ به دستگاه/دامنه دیگر باید دوباره فعال شود.
مهم: پاک کردن داده‌های سایت ممکن است دیتابیس را حذف کند؛ فایل بکاپ را در مکان امن دیگری نگهداری کنید.
برای قابلیت‌های رمزنگاری و اثر انگشت، برنامه را روی HTTPS یا localhost اجرا کنید.
این نسخه دیتابیس محلی دارد؛ همگام‌سازی ابری یا سرور ندارد.
